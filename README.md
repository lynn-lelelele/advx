# Echo · 夜声

> 🏆 AdventureX 2026 黑客松参赛项目

**Echo** 是一个深夜情感陪伴应用——当你有无处安放的情绪时，对着它说出来。AI 倾听并回应你，当发现有人和你有相似的感受时，为你牵线搭桥。

## 为什么叫 Echo

每个人在深夜说出去的话，都希望能听到回音。Echo = 回声。

## 核心功能

| 功能 | 说明 |
|------|------|
| 🎙️ **语音倾诉** | 按住说话，松开发送，用声音比打字更真实 |
| 🤖 **AI 对话** | AI 倾听你的情绪，给的不是建议，是陪伴 |
| 💞 **共鸣匹配** | AI 发现有人和你感受相似 → 匿名开启对话 |
| 🌙 **深夜美学** | 深色背景 + 暖色微光，安静不刺眼 |
| 🥚 **复活节彩蛋** | 某个角落藏了点小惊喜 |

## 技术栈

| 层 | 技术 |
|----|------|
| **框架** | uni-app（跨平台） |
| **前端** | Vue 3 + TypeScript |
| **构建** | Vite |
| **状态管理** | Pinia |
| **目标平台** | iOS / Android / H5 / 微信小程序 |

## 项目结构

```
src/
├── pages/
│   ├── loading/      ← 启动页
│   ├── ai-chat/      ← AI 对话（核心）
│   ├── user-chat/    ← 用户间对话（匹配后）
│   ├── message/      ← 共鸣墙
│   ├── profile/      ← 个人中心
│   └── easter-egg/   ← 🥚
├── components/       ← 通用组件（ChatBubble 等）
├── stores/           ← Pinia 状态管理
├── api/              ← 接口层
└── static/           ← 静态资源
```

## 如何运行

```bash
# 安装依赖
npm install

# H5 开发模式（浏览器）
npm run dev:h5

# 微信小程序
npm run dev:mp-weixin

# App 开发（需要 HBuilderX）
npm run dev:app
```
